# ShareYourMons 0.3.1

ShareYourMons is a client-side Cobblemon PC collection viewer for the Cobblemon Town community.

It helps players find custom skins, shinies, and Legendary or Mythical Pokémon, browse an organized collection report, and copy that report to the clipboard.

## What’s new in 0.3.1?

This release changes the project’s player-facing name from Collection Exporter to ShareYourMons.

The in-game title, launcher label, and version footer use the new name.

The internal Fabric mod ID remains collection-exporter for compatibility.

There are no intentional functional changes from 0.3.0.

## Features

* Custom skin, Legendary/Mythical, and Shiny filters.
* Scrollable in-game collection report.
* Grouped skin families and duplicate counts.
* Optional PC box and slot locations.
* Local clipboard copy.
* Refresh to read the current client-visible PC state.
* Separate reporting for unknown or conflicting skin information.

## Requirements

* Minecraft 1.21.1.
* Fabric Loader 0.18.0 or newer.
* Fabric API 0.116.7+1.21.1 or newer.
* Cobblemon 1.8.2.
* Java 21 or newer.

Install on the Minecraft client only.

## Installation

Download one of the JAR files attached to this release and place it in your Minecraft mods folder.

Open the Escape menu in-game and select ShareYourMons. When multiple compatible Swamp Mods are installed, the option may appear inside a Swamp Mods selector.

Do not install more than one filename from this release.
